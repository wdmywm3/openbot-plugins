# 邮箱

在实例主人的私聊中收发邮件、跟进新来信。Gmail 连接直接使用 Google 邮箱中的会话、标签和草稿。其他服务商可用 IMAP 收件、SMTP 发件。每个实例连接一个邮箱。

在 OpenBot 的扩展市场搜索「邮箱」，安装后按提示授权并准备依赖。使用下载的 ZIP 时，先解压，再通过「导入插件」选择包含 `plugin.json` 的目录。

## 连接 Gmail

1. 在自己的 Google Cloud 项目中启用 Gmail API，配置 OAuth 同意屏幕，并下载「桌面应用」类型的 OAuth 客户端 JSON。项目处于测试状态时，将自己的邮箱加入测试用户。
2. 在实例的「邮箱」设置中选择「Gmail」，填写自己的 Gmail 地址，把下载文件的 JSON 内容粘贴到「Google OAuth 客户端或授权凭据」，保存并启用插件。
3. 点击「连接 Google」，在这台电脑的浏览器中登录同一邮箱并授权。授权成功后，将本机网页显示的凭据复制回同一个设置项，保存后关闭网页。授权码使用本机回调和 PKCE；插件用实例的加密凭据保存刷新令牌。
4. 在主人私聊说「查看已连接的邮箱账号和收件箱未读数」。需要断开时，在 Google 账号的第三方连接管理中撤销该应用授权，并清除实例中的授权凭据。

也可以在装有 Node.js 20.19 或更新版本的电脑上，在本目录运行 `node authorize-gmail.cjs "桌面客户端.json"`，按终端给出的 Google 地址完成同一授权。Google Workspace 管理策略会影响可授权的范围。[Google 桌面应用授权](https://developers.google.com/identity/protocols/oauth2/native-app) · [Gmail API 的权限范围](https://developers.google.com/workspace/gmail/api/auth/scopes)

## Gmail 中可以做什么

| 操作 | 在私聊中这样交办 |
| --- | --- |
| 查询账号、标签和计数 | 「我的收件箱还有多少封未读邮件？」会直接读取标签计数。 |
| 搜索邮件或只列编号 | 「找出最近一个月招生办发来的带附件邮件。」支持 Gmail 原生搜索语法、标签编号和翻页。 |
| 读取单封、批量邮件或整串会话 | 「把这两串往来按时间顺序整理给我。」支持通过邮件编号找到会话、保留回复顺序、选择元数据或 MIME 正文。 |
| 读取附件 | 「把这封邮件里的材料清单保存到本机。」返回保存路径，支持文本摘录和常用图片预览。重名时可按部件编号选择。保存后的附件也可直接附到同一聊天的新邮件中。 |
| 管理草稿 | 「起草一封回信，放到 Gmail 草稿箱。」可以列举、查看、修改、丢弃和发送。只改标题或收件人会保留正文和附件；提供新正文或附件会替换原 MIME 正文。 |
| 新建、回复、全部回复、转发 | 「回复所有人，说明周五前可以补齐材料，抄送给……。」支持抄送、密送、已验证的 Gmail 发件别名、Reply-To、HTML、聊天附件和 MIME 部件。转发多封时每封独立发送，原邮件和附件作为完整的 `.eml` 保留。Workspace 分类标签可随新信或草稿提交。 |
| 标签与批量整理 | 「建一个『申请』标签，给符合这个搜索条件的邮件都加上；保留已有标签。」可以按标签名称或编号操作，多页搜索先收集编号，再分批修改。 |
| 已读、星标、归档、回收 | 「把这一串归档，再把那封重复通知移到垃圾箱。」归档移除整串邮件的收件箱标签。垃圾箱中的邮件可恢复。 |

发信回执表示服务商已受理。发送结果不确定时，插件保留本次提交记录；先核对邮箱的已发送记录，再决定是否另发。发送已有 Gmail 草稿时，寄出的是邮箱里当时保存的版本。

## 连接其他邮箱

选择「IMAP / SMTP」，填写邮箱账号、IMAP 服务器和授权码。收件默认 TLS 端口 993，发件默认 TLS 端口 465。587 端口强制 STARTTLS，其他 STARTTLS 端口可写成 `starttls://mail.example.com:2525`。SMTP 凭据与 IMAP 相同时可留空 SMTP 授权码。旧版 IMAP 配置、收件箱邮件编号和关注条件继续有效。

| 邮箱 | 收件服务器 | 默认发件服务器 |
| --- | --- | --- |
| QQ 邮箱 | `imap.qq.com` | `smtp.qq.com` |
| 网易 163 | `imap.163.com` | `smtp.163.com` |
| 允许应用密码的 Gmail | `imap.gmail.com` | `smtp.gmail.com` |
| 自建或其他邮箱 | 服务商提供的加密 IMAP 地址 | 在实例设置中填写 SMTP 地址 |

可以查询和创建文件夹，按发件人、主题、未读或星标筛选，读正文和附件，修改已读和星标，移动、归档及移入垃圾箱。移动要求服务端提供 MOVE；没有声明归档或垃圾箱路径的服务可以明确指定目标文件夹。IMAP 模式的可编辑草稿保存在原聊天，发送走 SMTP。要求 Microsoft OAuth 的 Outlook 账号暂未接入。

## 新邮件提醒与大小限制

在主人私聊说「关注主题里有『补材料』的新邮件」，或「关注招生办发来的新邮件」。开始关注时建立基线，每个聊天保存一组条件。OpenBot 运行期间约每两分钟检查，断线后从已保存的位置补查。Gmail 按邮箱历史记录增量检查，IMAP 按邮件编号检查。命中后把来源和正文摘录交给原私聊的主 Bot。可以查看或停止关注；Gmail 的历史游标过期时，需要重新关注。

附件下载上限为 6 MiB，每封信最多添加 8 个聊天附件，合计上限为 6 MiB。附件保存在插件本机数据目录中，聊天中会返回实际路径。批量读取最多选择 100 封，单批返回上限 1 MiB。Gmail 的长正文会标记截断，可用 raw 格式读取原信；非常大的邮件仍受返回大小限制。
