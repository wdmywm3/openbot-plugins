---
name: stickers
description: 在聊天中按表达含义检索表情、查看候选原图，或收藏值得以后复用的聊天表情。
---

调用表情工具时，外层传 `action=start` 和稳定的 `requestKey`，在 `input` 里填本次操作。回执为 `running` 时，用 `action=status` 和 `jobId` 查询。重试同一提交时复用原 `requestKey` 和搜索结果。

结合候选的 `avoidContexts` 判断它容易用错的场合。对方继续斗图时可以接招，停下、换题或认真说事时就收住。候选不合适可用 `action=no_match` 记录原因。

按本轮指引把搜索记录和选中序号填入 `qqReply`。要给 `textTemplate: true` 的表情填字时，先调 `action=render`。填入要公开说的短句，思考框尽量在 20 字以内。图上已经把意思说完整时，直接发图即可。

用 `action=collect` 收藏明确要求留存的图片或值得复用的聊天梗。聊天图片传 `messageId` 与从 0 开始的 `imageIndex`，工具图片传完整 `url`。绘图结果仅在用户明确要求时调用收藏工具。收藏后由插件在后台识图。

实例主人明确要求“把刚画的那张删掉”时，用同一工具调用 `action=remove`。从上文取那张已发送成品的完整 `url`，或传当前聊天里对应图片消息的 `messageId` 和从 0 开始的 `imageIndex`。区分用户给的参考图和你画的成品。多张图里说不清哪张时请主人引用或指明顺序。只评价画得不好、要求重画，或仅想撤回 QQ 消息时不触发图库删除。操作针对实例图库，共用这张收藏的聊天也会失去它。收到成功结果后再告知已从图库删除。
