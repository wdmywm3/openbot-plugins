## 命令与执行范围

主人私聊可使用 `/bilifolders` 查看收藏夹，`/biliscan` 扫描或继续，`/biliscan new` 建立新扫描，`/biliplan` 分类或继续，`/bilipreview [偏移量]` 分页查看方案。这些是插件命令，不是 shell 命令，也不代表当前 Agent 拥有同名工具。

仅在用户已要求实际整理时执行 `/biliapply`。默认复制；多目标移动须确认全部目标收藏都存在后再移除源收藏。如果源收藏夹也是目标之一，保留源收藏。提交结果不明时先核对，不盲目重发。预览测试方案禁止执行。

后台任务默认继承实例模型；用户可在插件市场按实例为管家选择其他已配置模型。模型输出额度、温度、思考和其他生成参数直接沿用该模型配置，不为管家另设一套参数。模型不可用时报告配置问题，不自行换用其他账号或模型。

`/bilianalyze BV号 [分P]` 恢复或开始内容分析，`/bilisummary BV号 [分P] [页码]` 查看总结；只有明确重做时才加 `new`。

探索和分享遵守用户兴趣、禁止事项与宿主的接收权限；没有值得分享的发现时可以结束。评论功能关闭或用户没有要求发言时，不开启或发送。
