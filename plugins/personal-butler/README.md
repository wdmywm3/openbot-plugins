# 私人管家

同一个插件可以用于 QQ 和微信实例。QQ 由实例主人在本人私聊使用。微信由扫码绑定的用户在该聊天使用，启用插件后无需另外设置主人名单。各实例的事项、记忆引用和提醒保存在原聊天。微信功能需要含微信聊天授权和后台任务支持的 OpenBot。

## 自动跟进

聊天进行时，管家会分批整理用户消息、主 Bot 查过的资料和分身报告。主 Bot 发出一段回复后，这一轮后续查到的资料仍会进入同一事项。它也能把分析中发现的待查问题直接留给管家，附上相关的聊天原话。管家在后台整理，聊天回复可以照常发送。

聊天停下来后，管家可以结合最近私聊和同一聊天中仍有效的偏好、事项，找出下一步能查清的问题。它会用公开资料核对，把查到的结果、出处以及待查的问题留在原事项里。一轮自主查证最多连续检查三次，发现新的具体问题或有价值的复查时点才会安排下一次。依赖的记忆被修改或撤销后，管家会重新判断该查什么。

例如帮你找免费的录屏软件时，管家查到某款只有 14 天免费试用，会主动把限制和来源记下来。你选了该软件，管家可以从选用时点安排一次回看，提醒你留意试用条款。它会保留开通日未知的状态。有真实开通日期的证据时，才显示实际试用到期日。网页写明固定限免截止日时，直接按公开期限跟进。

可以主动发现归档工具的导出限制、服务认证变更或报名新增材料，也会把准备办理、已提交、改期和结束等进展合并到同一事项。重要新发现交给原聊天的 Bot 决定是否用主动消息告知。Bot 已经发过同一原文时，管家保留发现和出处，并撤回相同的待发提醒。

可以问「我现在有哪些事在跟进」或「查到了什么」。说「这项只记录，不用提醒」会撤回待处理的通知并保留跟进。说「这项不用跟了」会结束跟进。

应用需运行才能检查并安排通知。平台连接或发送凭证暂不可用时，仍有效的通知会等待原聊天可发送。日期按本机时区计算，带时区的时间按原时区解析。

## 从记忆 Plus 移交

同时启用记忆 Plus 2.6.2 和私人管家。如果一项单次复查尚未到期、也没有运行记录，可以在原私聊说「把检查 X 的那一次复查移交给私人管家」。移交前先从原聊天确认对应的事项。管家接手到期检查，只读现有获准资料，有可核对的新进展才把结果交给主 Bot。已有周期、订阅或运行记录的复查继续按原设置管理。

## 网页跟进和长期偏好

可以交办一条公开网页，例如「帮我跟进 https://example.com/releases ，只提醒稳定版」。第一轮检查建立基线，此后约每 15 分钟核对一次。发现符合条件的变化时，管家把原文证据交给同一聊天的 Bot，由它判断是否发提醒。

可以在原聊天问「我现在跟进了哪些网页」「给这项追加条件，只提醒正式发布」「停止这项跟进」。明确说「请记住，只在稳定版发布时提醒我」会把该偏好和来源一起写入统一记忆。单条跟进的条件保存在事项里。

检查读取无需登录的 HTTPS 页面正文。交办消息写出完整链接，重定向页面请提供最终地址。启用或升级时需授权聊天资料、回复送达和任务结果通知、模型、后台任务及公开网页访问。管家发送的跟进事件绑定原实例与原聊天，主 Bot 通过该聊天发送。发送账号或数据恢复状态变化后，从新消息开始建立新的事项。
