# Watch 视频阅读

Watch 0.6.0 将视频读取做成一个插件包：Skill 指导阅读，工具负责预览、视频下载、画面提取、字幕读取、补看与取消，`watch_media` 为其他插件提供异步媒体读取。它使用 OpenBot 的 Skill 与 MCP 接口，业务逻辑和校验全部在本包内。适用于启用此插件的群聊、私聊和任务，不需要给聊天开放 Shell。

`watch_preview` 直接读取B站指定分P的平台预览拼图，最多返回三张低清画面，不下载或解码视频。需要 Pillow（已列入 requirements-media.txt）；返回实际采样时间与请求时间。它适合初筛题材和风格，具体过程、小字或语音仍需按问题补读。预览不可用时返回 unavailable，由调用方决定是否读取原视频。B站小管家 1.12.0 默认绑定此预览工具，需要支持 `preview` 媒体能力的 OpenBot；旧版宿主继续原视频阅读路径。

B站小管家 1.9.0 默认通过 `watch_media` 补读语音和画面。两者在同一实例启用并授权后即可使用；回执按调用方和任务范围隔离，已有任务不会因查询而重新下载，后续补看可复用本范围的来源文件。语音请求实际调用已配置的转写模型，不把字幕冒充语音转写；缺少模型时明确返回不可用。抽样画面保留实际时间及未采样间隔。

支持 HTTPS B 站视频、b23.tv 短链接、YouTube 视频，以及主动导入的本地视频。画面交给当前模型理解，不额外接入分析模型。字幕优先选择原语言的发布者字幕或自动字幕，避免把自动翻译当成原文；无字幕时使用配置好的本地 faster-whisper 模型。

## 安装和运行

1. 使用支持依赖安装的新版本 OpenBot。安装弹窗会使用自带 Python 和 uv，按 requirements-media.lock 准备独立环境，并下载 FFmpeg/ffprobe 与 Deno；无需手动安装 Python 或修改系统 PATH。旧版宿主仍需自行准备这些依赖。
2. 在 OpenBot 的插件管理中导入本目录或从市场安装，在插件详情打开运行开关；再在目标实例或主人私聊中允许暴露插件工具。安装完成和启动状态分别以实际结果为准，查看画面需要支持图片的模型。
3. 向 Bot 提供视频链接和问题。`watch_info` 可检查依赖；不要用执行脚本代替缺失的工具权限。

手动部署到其他宿主时，可从插件目录安装下载依赖：

```powershell
python -m pip install -r requirements-media.txt
```

插件优先使用当前 Python 环境中的 yt-dlp。B 站的 WBI 兼容处理需要这个 Python 包；YouTube 所需的 EJS 组件由 `yt-dlp[default]` 提供。`watch_info.download_runtime` 分别报告 Python 下载包、EJS 和 Deno 是否可用。

`mcp.json` 使用 `${PLUGIN_ROOT}` 与 `${PLUGIN_DATA}`，没有硬编码宿主路径。每个实例有独立的数据目录。MCP 是包内工具的传输方式，无须另装一个“媒体 MCP”插件。

工具包括 `watch_info`、`watch_start`、`watch_status`、`watch_frames`、`watch_transcript`、`watch_cancel`。工具参数以发现的 JSON Schema 为准。服务通过 stdio 运行，标准输出只用于 MCP 消息。

## 什么时候读取、如何重看

群聊、私聊与后台任务统一按上下文判断：只有视频内容影响当前理解、回答或任务结果时才读取。已有文字足够时保留附件，不因为收到视频而自动解析；也不要求用户必须说出特定关键词。

短任务可由主 Agent 读取；长片、多个视频或耗时转写可交给已授权的后台子代理。支持 `subagent.start(background: true)` 的 OpenBot 会让当前聊天继续处理其他消息，任务结束后排队通知主 Agent 读取报告、决定是否补充回复。子代理不直接向 QQ 发消息。停止实例或退出应用会取消后台任务；没有可用子代理时仍可使用 Watch 自己的异步任务。

要求重看时，用缓存的 `watch:<job_id>`、新请求编号和新的时间范围或采样点重新取证；已完成的子代理也可以通过 `followup` 接受新问题。不能只把旧摘要重新转述。缓存过期则重新获取来源。

默认读取完整画面。代码、小字或按钮看不清时，可在补看请求中加入 `crop: {"x": 100, "y": 200, "width": 640, "height": 180}`。坐标以 `watch_status` 返回的 `media.width`、`media.height` 为准，表示原视频像素；从缩小后的整帧定位时需换算，不能直接照搬图片坐标。裁剪从缓存的原视频解码后进行，再按图片大小限制缩放，不放大低清截图。实际图片尺寸和裁剪区域随画面返回；不填写 `crop` 就继续读取整帧。

## 可选：登录与语音转写

来源允许匿名读取时可直接使用。网站也可能对公开视频要求登录验证；这时由主人把 Netscape 格式的 Cookie 文件放到本实例插件数据目录的 `cookies.txt`。本插件不会读取浏览器或其他应用的登录资料；Cookie 也不会返回给模型。请只使用有权访问的视频。

本地转写在运行服务的同一 Python 环境中执行 `python -m pip install -r requirements-asr.txt`，另行准备 [faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small) 模型目录，至少包含 `model.bin`、`config.json`、`tokenizer.json`。在插件数据目录新建 `settings.json`：

```json
{
  "asr_model_path": "D:/Models/faster-whisper-small"
}
```

重启该插件的 MCP 连接后生效。转写使用本地 CPU/int8，模型和分词器只从指定目录读取，不在工具调用过程中安装依赖或下载权重。音频由 FFmpeg 准备成单声道 16 kHz PCM，直接交给转写模型，避免再次经过 PyAV 解码。没有字幕且未配置转写时，结果明确标记缺少语音证据。模型和视频缓存均不打包进插件。

## 主动导入本地视频

主人在终端执行以下命令，其中数据目录须为该实例插件 MCP 的数据目录：

```powershell
python -B tools/server.py --data-dir 'D:/OpenBotData/mcp/ext-example' --import-file 'D:/Videos/demo.mp4' --subtitles 'D:/Videos/demo.vtt'
```

`--subtitles` 可省略，支持 VTT、SRT、JSON3 和 B 站 JSON 字幕。命令复制视频并返回 `import:<随机标识>`；把这个标识交给原会话即可读取。模型工具没有文件导入或目录枚举入口。任意 QQ 附件/CDN 链接目前需要先由主人保存并导入。

## 读取范围和缓存

- 每次最多处理 600 秒，视频最长 120 分钟、单文件最多 256 MiB。下载优先选择 1080p，按画面短边处理横屏与竖屏；没有该档位时选择可用的较低档位，只有更高档位时选其中最低的档位。结果报告实际源文件尺寸，低于优先清晰度时提示。登录和权限可能影响可用档位，网页播放器的清晰度设置不控制本插件。
- 长视频按区间继续阅读，首次仍需下载完整文件；提高画质不会解除文件与缓存容量限制。复用已有低清缓存不会自动变成高清，需要从原视频链接重新开始下载。
- 整帧与局部画面的长边最多 1920 像素，保留普通横屏或竖屏 1080p 的尺寸，不放大小尺寸视频。局部补看从原视频裁剪，保留原始像素细节；结果中的 `frame_view` 及图片文字说明区分整帧和裁剪画面。
- 默认最多 12 张画面，可设为 2–24 张。定时锚点覆盖整个区间，再补充场景变化；每次向模型返回最多四张图片。只合并字节完全相同的图片，保留所有观察时间戳。
- 用 `watch:<job_id>` 复用原文件，选择新范围或具体时间戳。结果始终报告实际处理区间、采样时间、最大观察间隔和字幕来源；下载到预览或短文件时会提示。
- 同一服务串行处理视频，最多四个未完成任务。下载/抽帧/转写有超时、容量限制与取消。服务重启后将未完成任务标为中断，不自动重放。
- 缓存上限 2 GiB，最多 64 个任务。任务及导入文件保留约 24 小时，在服务启动或队列空闲时的新请求触发清理；达到限额时拒绝新任务。
- 数据按实例隔离。任务标识是不可猜测的读取凭证，无任务列表接口。MCP 当前未向本服务传递经过验证的聊天身份，因此这些标识不能作为严格的跨聊天身份隔离；Skill 要求只在原任务内使用它们。

## 开发验证

在插件仓库运行 `npm run test:watch`。测试覆盖输入、B 站兼容分支、字幕、时间覆盖、分页、取消、缓存复用、重启和 PCM 读取；有 FFmpeg 时还会生成短视频并验证真实抽帧、1080p 整帧和从 4K 原视频裁剪细线，通过 stdio 协议读取原生图片。下载格式测试使用 yt-dlp 的真实选择逻辑但不联网，覆盖横屏、竖屏与清晰度回退。PCM 数值测试需要转写环境中的 NumPy。

`node tests/watch-host.cjs <OpenBot源码目录>` 额外使用宿主实际的包解析器、MCP 客户端和图片转发逻辑验证兼容性。这个路径仅用于开发验证，插件运行不依赖源码目录。

源码可直接导入开发版 OpenBot。正式市场目录固定到 Git 提交，需完成发布流程后再生成 catalog。上游参考与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

本轮使用 yt-dlp 2026.10.21、faster-whisper 1.2.1、PyAV 19.0.2，以及本地 base/small 模型；最终三个成功用例使用 small。中文转写仍可能出现谐音词或项目名误识别，阅读 Skill 要求结合画面复核。

B 站修复针对页面缺少初始化数据的情况：插件通过同一视频的 WBI 接口补全信息，保留原下载器的访问权限、分 P 和格式处理。下载与字幕阶段复用取得的信息。语音修复针对新版 PyAV 与 faster-whisper 的解码接口不兼容；准备好的 PCM 现在直接传入模型。宿主业务代码无须随这些适配修改。

真实验收脚本为仓库中的 `tests/watch_live.py`。提供独立的 `--data-dir`、本地 `--model`，通过 `--bilibili` 指定视频，`--jfk` 指定已下载的官方样本；`--youtube` 为显式启用的测试，不在默认回归中联网。它保存实际读取范围、画面和转写结果，模型权重需要提前准备。
