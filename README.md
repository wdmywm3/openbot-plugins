# OpenBot 插件

## 搜索

网页搜索、网页阅读和以图搜图，分别配置服务，由 Bot 按任务选择工具。网页支持 AnySearch、Tavily、Exa、Brave，图片搜索支持 Google Cloud Vision。

[安装与配置](plugins/search/README.md)。

## 梗百科

查询网络梗和缩写，提供本地 6668 条词库、图片卡片、自动查词和增量更新。0.3.0 移除了自定义黑话管理与相关命令，原有数据保留。

原作者：[in1t1a1](https://github.com/in1t1a1/astrbot_plugin_memewiki)。[安装与使用](plugins/memewiki/README.md)，[下载 0.3.0](https://github.com/wdmywm3/openbot-plugins/releases/tag/memewiki-v0.3.0)。需要支持 50 MiB 插件包和新版市场目录的 OpenBot。

## B站小管家

根据兴趣浏览 B 站，阅读视频、保存笔记，并把适合当前聊天的内容分享给群友。支持扫描收藏夹、生成分类方案，预览后再整理收藏。

可分别管理大号和小号，按需启用点赞、收藏、评论、回复和私信。视频阅读可配合 Watch，结合字幕和画面继续分析或回答追问。

## bPhone

让 Bot 使用已绑定的安卓手机或模拟器，查资料、浏览内容、使用应用、玩游戏，或完成主人交办的任务。可以查看活动进度，并继续上次中断的任务。

按需使用与闲时自行活动分别设置，可选择允许使用的应用、兴趣方向和活动频率。一个实例可以绑定多台设备。

## Watch 视频阅读

阅读聊天视频附件、HTTP/HTTPS 视频直链、yt-dlp 支持的平台页面与配置目录内的本地视频，总结内容、梳理教程步骤，并按时间点回答问题。平台页面优先通过内置浏览器在线取帧、读取字幕并按需采集片段音频。画面通过图片交给模型，不要求原生视频输入；有字幕时优先读取原语言字幕，无字幕时可配置语音转写。

默认优先获取1080p画面，通过编号分镜图和对应字幕了解内容，再按分镜编号或时间点高清补看。自动采样会按画面变化与字幕密度分配，并选择清晰帧；代码、小字或按钮仍可从原视频裁剪核对。

分镜设计与部分算法参考或改编自 [SAOS-3624/dsh-video-storyboard](https://github.com/SAOS-3624/dsh-video-storyboard)，感谢原作者以 MIT 许可开源。详情见 [Watch 鸣谢与许可](plugins/watch/THIRD_PARTY_NOTICES.md)。

## 内容监控

订阅 B 站 UP 主和 RSS／Atom 订阅源，定时检查新内容并推送到指定群聊或私聊。支持多个订阅和自定义推送模板，也可以随时查看监控状态或立即检查。

## 骰娘

群聊跑团工具，支持通用掷骰、暗骰、CoC 7 版检定与对抗检定。可管理角色卡，进行理智、技能成长和 D20 优势／劣势检定，抽取疯狂症状并查看掷骰统计。

使用 `/dicehelp` 查看命令和骰式示例。

## 每日签到

按群聊或私聊记录每日签到、连续天数和积分，提供当前聊天的积分排行。可设置签到积分范围、时区和排行榜人数。

使用 `/checkin` 签到，使用 `/checkinrank` 查看排行。

## 群聊总结

总结当前群聊的近期消息，整理主要话题、结论和待办。可以直接使用 `/groupsummary`，也可以指定关注点，例如 `/groupsummary 今天讨论的活动安排`。

## 随机工具箱

提供抛硬币、生成范围内的随机整数、从多个选项中抽取一个，以及随机抽取群成员等功能，适合日常选择、抽签和群聊互动。

## 表情素材库

管理导入、聊天收集或 QQ 收藏的素材，按角色与聊天选择可用表情。固定用法与版本化可用状态分开，冷却状态带截止时间，发送前重新检查可用性；QQ 收藏同步仅用于支持该接口的实例。

2.3.0 增加文字与多条件筛选、批量选择和明确的发送范围设置。编辑页面使用宿主弹窗，标题和保存区固定，点击外部或按 Esc 可关闭；未保存的修改会先提示。

2.3.1 在聊天筛选、范围设置和聊天设置中统一显示“群名（群号）”，支持按群名或群号搜索。群名读取和断线缓存需要 OpenBot 0.1.94 或更新版本。

## 记忆 Plus

正文保存在宿主统一记忆中，插件负责自动召回、整理和复查。定时整理与索引维护分开；整理按固定来源上界分批继续，暂停后可恢复。相同候选合并证据，整理只使用实际聊天。私聊事项可明确设置单次、周期或有新证据时复查，无新进展保持安静。

2.4.0 按聊天复用持续整理会话，按内容容量从旧到新追加，通过工具查询、核对和提交记忆。人物画像来自本人确认的事实与偏好，并按群聊分别保存；事件事实与事项另存，常用称呼和别名保留。暂不自动新增经历；定时整理和临时关注分别开关。请先安装本次配套的 OpenBot 0.1.98 或具备同等功能的新宿主，再更新插件。[使用与兼容要求](plugins/memory/README.md)。

2.3.0 的整理设置默认放在实例的“记忆 → 整理”中，也可在实例插件设置中改为独立分类。设置自动保存，支持实例默认值和聊天覆盖；暂停自动整理与停止当前任务分别操作。

2.3.1 将文字、图片和图文混合的自动召回资料统一插入到对应发言之后；多张图片分别查询并合并去重，普通聊天图片也会分批进入向量索引。同时修复多图聊天的 32 MiB 进程消息超限，保留模型完整的图片输入。此版本需先升级至 OpenBot 0.1.91 或提供清单所声明能力的更新版本。

2.3.3 修复实例已开启整理、后台却按关闭处理的问题，升级后沿用已保存的闲置时间与聊天覆盖。整理和记忆使用评估的 Token 归入“记忆整理”；需要 OpenBot 0.1.92 或更新版本。

2.3.4 将自动召回限定为当前回复目标的正式记忆匹配，最多四条，检索预算约两秒。原始聊天与图片历史由 `recall` 工具按需查询，保留已有索引与整理设置。

记忆 Plus 2.3.0 和表情包 2.3.0 需要支持插件导航 v2 与宿主弹窗的新版本 OpenBot（`pluginNavigationV2`、`pluginOverlays`）。安装时会检查所需功能，请先更新宿主，再更新插件。

表情包 2.3.3 将角色自带图片同步为“专属角色表情”，提示模型在贴合语境时优先选择。需要支持分页角色媒体和分批后台任务的新版本 OpenBot，请先更新宿主再更新插件。

角色市场提供嘻嘻 1.1.14 和 33 张配套表情。角色和表情分别下载，可在招募时跳过表情并在之后补装；使用表情需安装并启用表情包插件。需要支持角色包格式版本 2 的新版本 OpenBot，旧版会拒绝更新以保留已有表情。

## 开发验证与候选包

测试使用 Node.js 24。独立检出插件仓库后，先运行 `npm ci --prefix plugins/memory --ignore-scripts` 和 `npm ci --prefix plugins/meme-library --ignore-scripts` 安装锁定依赖，再运行 `npm test`。这个入口不读取 OpenBot 源码，包含记忆策略的独立测试和表情图片引擎测试；GitHub Actions 使用同样的环境执行。

`npm run test:integration` 执行记忆宿主测试、表情／词库／搜索／视频宿主测试、配置页面和 Python 集成；`npm run test:all` 执行独立测试和完整集成。开发时用 `OPENBOT_HOST_ROOT` 指定宿主源码，`WATCH_TEST_PYTHON` 与 `MEMEWIKI_TEST_PYTHON` 指定测试环境；默认使用本仓库已有的 `.venv-watch-full` 和 `.venv-verify`。集成环境或依赖缺失会明确失败，不静默略过。`npm run test:memory` 为记忆宿主测试的单独入口，包含持续整理与人物画像检查；CI 的独立记忆入口为 `npm run test:memory:unit`。

`npm run prepare:candidates -- <新目录>` 为当前工作区生成 12 个本地安装目录、ZIP 和内容摘要，`npm run prepare:candidates -- <目录> --verify` 重验。它们是未发布候选；正式发布仍用真实提交运行 `npm run catalog -- <提交SHA>`，不可用工作区摘要伪造远端提交。
